# HomeBnB

A React application inspired by Airbnb that showcases vacation rental properties.

## Features

- Header with navigation menu
- Banner component using props
- Reusable Button component using props
- Gallery component displaying 4 property images
- Footer component
- Styled with CSS

## React Concepts Used

- Components
- Props
- JSX
- map() method
- CSS Styling

## Components

### Header
Displays the site title and navigation links.

### Banner
Receives title and text through props.

### Button
Receives text and style type through props.

### Gallery
Receives an array of images through props and uses map() to display them.

### Footer
Displays copyright information.
